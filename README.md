
# SnowTrack

## Project Description

SnowTrack is a Python application designed to organize and analyze snow depth measurements using photographs collected from remote cameras in Alaska.

The project is based on environmental monitoring work involving remote cameras and snow measurement gauges at the Geographic Information Network of Alaska (GINA), University of Alaska Fairbanks.

The goal is to make it easier to review photographs, record snow depth measurements, and monitor snow accumulation in remote locations.

## Planned Features

- Access photographs collected from remote cameras.
- Organize images by date and time.
- Display photographs in a simple graphical interface.
- Allow users to enter snow depth measurements.
- Save measurements to a CSV file.
- Create graphs showing snow accumulation and melting.
- Explore automatic snow depth detection using image processing.

## Python Tools and Libraries

- Python - Main programming language
- Tkinter - Graphical user interface
- Pillow - Image viewing and processing
- Matplotlib - Graphing snow depth measurements
- OpenCV - Potential automatic snow depth detection
